# Викторина — Провери знанията си

Учебно приложение, създадено с HTML, CSS и JavaScript
като част от обучението ми с помощта на AI.

## Възможности

- Показване на въпроси с няколко възможни отговора.
- Един опит за отговор на всеки въпрос.
- Оцветяване на избрания отговор и съобщението за резултата.
- Преминаване напред след избран отговор.
- Броене на верните отговори и показване на крайния резултат.
- Бутон за започване отначало.
- Оформление за различни размери на екрана.

## Какво упражних

- Масиви от обекти и работа с индекси.
- Функции и обхват на променливите.
- Обхождане с forEach.
- Създаване на HTML елементи чрез JavaScript.
- Обработка на клик с addEventListener.
- Управление на състоянието чрез променливи.
- Промяна на CSS класове с classList.
- Flexbox, hover, disabled и media queries.
